# 按标题正则忽略会话通知 — 用户验证

日期：2026-10-10

本地实例：http://127.0.0.1:4180 ，**刷新页面**（或硬刷新）后生效；构建产物已部署到当前运行实例。

## 验证场景

1. **设置页出现新一栏**：设置 → 通知，最下方「忽略会话」应显示一个输入框，内容为默认规则 `^Telegram ·`，右侧有「恢复默认」按钮。
2. **默认规则生效**：让一个 `Telegram · …` 会话跑完一轮（或从 IM 发一条消息触发），浏览器不应在页面内/系统通知栏弹出「任务完成」，也不应有提示音；同一时间普通会话的通知照常。
3. **规则可编辑**：把输入框改成一行无意义正则（例如 `(` ），输入框下方应提示「无效正则，已跳过：\(」；清空输入框后普通 `Telegram ·` 会话通知恢复。

## 说明

- 命中规则只影响通知与提示音，不改变会话本身的行为。
- 若场景 1 看不到新一栏，说明浏览器仍在用旧 bundle，请硬刷新（Cmd/Ctrl+Shift+R）。
